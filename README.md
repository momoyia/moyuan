陌缘 健身减脂训练计划 App · 产品与UI设计文档

一、 产品概述与核心定位

应用名称：陌缘

应用定位：专注于科学减脂与个性化训练指导的移动端应用，为都市白领与健身爱好者提供系统的训练教程、饮食指导与进程追踪。

设计风格：优雅美学与功能平衡，清新柔和的渐变配色，纯白背景，大圆角模块化布局，通透沉浸的 iOS 交互体验。

品牌配色：主色调采用 #FD375E 到 #F73DD0 渐变，搭配低饱和度粉色底色 (#FFF1F4) 与纯白容器。

二、 信息架构与四大核心页面

1. 首页 (Home)

顶部区域：用户问候语、连击打卡天数统计（如连续打卡 12 天）。

燃脂计划组件：展示今日核心训练计划（如全身高强度间歇燃脂 HIIT）、时长、消耗千卡及达成进度条。

快捷分类标签：横向滚动标签（全部推荐、腹肌撕裂、马甲线塑造、有效臀大肌、拉伸放松）。

精选教程列表：图文结合的精选健身视频与训练课程，支持一键播放与详情查看。

2. 发现 (Discover - 减脂健康餐)

头部导航：发现页面标题与全局搜索入口。

专题 Banner：7天轻断食低脂营养餐单指南。

分类导航：减脂主食、高纤沙拉、优质蛋白、燃脂饮品快捷入口。

膳食食谱列表：展示牛油果全麦鲜虾轻食碗、香煎鸡胸肉配烤时蔬等高蛋白食谱及详细营养成份计算。

3. 精选 (Featured - 训练百宝箱)

标题导航：热门专题、科学减脂、核心突破、康复拉伸。

横屏卡片区：限时热门特训专题（如21天马甲线与腹肌速成班）。

经典动作库：高效减脂标准动作拆解（波比跳、平板支撑、深蹲跳）与组数频率建议。

知识分享：健身锻炼科学知识专栏文章。

4. 我的 (Profile)

个人信息区：默认昵称“鸡蛋炒饭”、Lv.4 达人勋章、个性签名、编辑个人资料入口、右上角设置。

数据统计面板：累计运动时长、消耗热量、完成课程节数。

功能菜单：

收藏的健身教程

制定个人健身计划

运动的进程与数据追踪

三、 设计规范说明

栅格与尺寸：基于 iPhone 15 Pro 高保真移动端视图设计，圆角半径保持 rounded-2xl 至 rounded-[50px] 的视觉统一样式。

排版字体：优先采用 Plus Jakarta Sans 英文西文数字与苹方中文字体栈。

微交互：按钮与卡片悬停伴随柔和缩放与阴影加深反馈，底部导航栏采用高斯模糊毛玻璃拟真效果。
